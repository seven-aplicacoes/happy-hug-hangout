# SEVEN Gestão — Visual Identity

## Typography
- Main/UI: `Motiva Sans` (locally hosted).
- Editorial: `Motiva Sans` (Semibold, tracking-tight). Classe `.font-editorial` e `.font-editorial-italic`. Usar em momentos editoriais (Login hero, Selecionar Ambiente, Títulos de seções).
- Google Fonts: Removida a dependência de `Instrument Serif` para maior legibilidade.
